# Changelog categories

| Heading | Use for | Usual bump |
|---|---|---|
| Added | new capability | minor |
| Changed | behaviour that existing users will notice | minor, or major if it breaks them |
| Deprecated | still works, scheduled for removal | minor |
| Removed | gone in this release | major |
| Fixed | a defect | patch |
| Security | a vulnerability | patch |

When one change fits two headings, pick the one the user would search for.
