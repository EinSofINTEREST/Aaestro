# Review checklist

## Structure

- The first paragraph says what the document is for
- Headings read as an outline on their own
- Steps that must happen in order are numbered

## Accuracy

- Every command is complete enough to paste
- File paths and flag names exist
- Version numbers and limits have a source

## Reader fit

- Terms are defined at first use
- Prerequisites come before the step that needs them
- Nothing essential sits only in an image
